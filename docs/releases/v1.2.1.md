# AMG v1.2.1

- Optional `bootstrap_files` inline startup context in `get_agent_brief` and MCP initialization instructions. AMG reads only regular files within `work_root` through `os.Root`. The entire rendered bootstrap section, including headings and notices, is at most `max_output_bytes` UTF-8 bytes after normalization and after decoding the MCP JSON response.
- The Skill catalog cache in `skills_models.go` opens each candidate `SKILL.md` once per scan. It fingerprints the directory name, nanosecond file mtime, file size, and bounded frontmatter block from that snapshot, then parses the same block on a cache miss. Both empty and populated catalogs are cached. Editing frontmatter invalidates the cache even when file size and mtime stay the same.
- `settings_get` and `settings_update` cover 14 live settings, including `bootstrap_files`, `annotations_mode` (`"default"` or `"trusted"`), and `default_yield_ms` / `max_yield_ms`. Running Shell sessions use the new bounds on their next wait. `"default"` preserves per-tool annotations, while `"trusted"` supplies uniform hints for private, single-owner deployments. Hosts still enforce their own approval policies. Numeric `session_id` handles use the 46-bit range `[1<<40, 1<<46)` and remain 13–14 decimal digits, avoiding scientific notation and rounding in 15-digit general formatting (`%.15g`).
- Long-term memory guidance points to the canonical on-disk archive. Read Obsidian `brain/` pages first, then `raw/transcripts/agentsview/` for exact wording. The former MemOS route is retired.

## Installation and verification

Linux amd64. Building from source requires Go 1.25+. Download the archive and checksums from [v1.2.1](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.2.1), follow the [README](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.2.1/README.md), and preserve your configuration and credentials.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

See [configuration](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.2.1/docs/configuration.md) and [changes](https://github.com/bsbofmusic/agent-mcp-go/compare/v1.2.0...v1.2.1).
