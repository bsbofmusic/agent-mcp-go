# AMG v1.0.1

AMG is a general-purpose remote agent workspace over MCP. This patch focuses on Chinese tool discovery, file-input compatibility, and tests that also work with restrictive file-creation defaults.

## Changes

- Chinese search splits Han and Latin runs, avoids single-character noise, expands general bilingual business terms, and reduces generic search-verb weights. Source identities still come from dynamic discovery.
- Source-scoped search and exact schema lookup reuse a matching fresh catalog when that source was successfully enumerated. Global scans report `incomplete` and `unavailableSources`, including sources not started before the overall deadline. A missing source catalog cannot be repaired by ranking, and a scan timeout does not by itself diagnose an upstream fault.

- Patch permission fixtures explicitly set their starting mode before checking that updates and rollback preserve it. CI runs unit tests with `umask 077`; the file-permission assertions remain unchanged.
- The portable `import_host_file` compatibility input continues to accept native file objects and pre-staged files. Only `import_chatgpt_file` advertises the host-native file parameter, whose schema is a file object rather than a union with a string.

## Installation and verification

The validated release target remains **Linux amd64**. Source builds require **Go 1.25+**; Shell requires a POSIX shell and Git operations require Git.

Release assets:

- `agent-mcp-go-v1.0.1-linux-amd64.tar.gz`
- `checksums.txt`

Download the [v1.0.1 release](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.0.1) and follow the [README quick start](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.0.1/README.md#quick-start). Verify the archive checksum before installing. Preserve your existing configuration and token; the fresh-install script deliberately refuses to overwrite them.

Reproducible source checks:

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

The main-branch CI for the exact release commit must pass before the release tag is created. Live integration tests require an explicit `AGENT_MCP_GO_CONFIG` path and their documented opt-ins. A skipped integration test is not evidence of a live call.

## Host-native attachments and review

AMG's protocol tests enumerate `import_chatgpt_file` on both HTTP endpoints and validate its file-object contract. They do not prove that an existing ChatGPT plugin has refreshed its tool inventory or has authorized a particular attachment. If that tool is absent in the host, collect the host's scanned tool list and refresh the connector's tool discovery before testing a real upload. Never invent a signed download URL or treat a `file_id` string as the authorized file object.

A native attachment test must start with the actual file selected in the host, save it through the native import tool, and verify its size and hash on the server. A synthetic HTTPS transfer test does not replace that result. Review cards and native download presentation also require a real client UI test. MCP-embedded exports remain limited to 32 MiB; larger files use the bounded HTTP transfer path and are subject to host/proxy limits.

## Compatibility and limits

Task scopes, stored checkpoints, the Bearer trust model, and the existing workspace/transfer interfaces are unchanged. Scopes are logical namespaces rather than ACLs, and Shell runs with the server OS user's permissions. Existing in-process catalog caching is disposable; the shared installation remains the source of truth.
