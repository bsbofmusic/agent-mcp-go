# AMG v1.1.5

Patch release resolving the browser `403 origin denied` consent submission failure during Gemini Web Connected Apps OAuth 2.1 linking and accepting optional `Bearer ` prefixes in the Owner passkey input.

## Changes

- **Same-origin `Referrer-Policy` on `/oauth/authorize`**: replaces `Referrer-Policy: no-referrer` with `Referrer-Policy: same-origin` on OAuth consent pages (`oauth.go`). Under WHATWG Fetch §4.5, `no-referrer` causes browsers to serialize `Origin: null` on `<form method="post">`, triggering `403 origin denied`. `same-origin` preserves the tuple `Origin` on same-origin form POSTs while sending zero `Referer` header across the `303 See Other` redirect to external OAuth callbacks.
- **Privacy-shield browser fallback via Fetch Metadata**: accepts `Origin: null` on `POST /oauth/authorize` strictly when a single browser-controlled `Sec-Fetch-Site` header equals `same-origin`, and rejects present-but-empty or duplicate `Origin` headers, keeping Brave / Firefox strict-privacy form submissions working while still rejecting cross-site or non-same-origin `Origin: null` requests (`403`) without consuming the one-time CSRF ticket.
- **Dual-format Owner passkey input**: evaluates both raw `<token>` and `stripBearerPrefix` (`Bearer <token>`, case-insensitive) in constant time when validating the consent form's Owner passkey field.
- **`write_stdin` post-exit deadline-clear race fix**: ignores `use of closed file` (`poll.ErrFileClosing`) when clearing the pipe deadline after `io.WriteString` already delivered all bytes and the child shell exited immediately, and builds the `TestExecutionLifecycleBinarySIGTERM` fixture with `CGO_ENABLED=0` matching release binaries.

## Installation and verification

The release target is **Linux amd64**; source builds require **Go 1.25+**.

Download `agent-mcp-go-v1.1.5-linux-amd64.tar.gz` and `checksums.txt` from [v1.1.5](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.1.5), verify the checksum and follow the [README](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.5/README.md#quick-start). Preserve existing configuration and credentials.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

See [security](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.5/docs/security.md) and [changes since v1.1.4](https://github.com/bsbofmusic/agent-mcp-go/compare/v1.1.4...v1.1.5).
