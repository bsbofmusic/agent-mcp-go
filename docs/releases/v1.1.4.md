# agent-mcp-go v1.1.4

## Summary

`v1.1.4` hardens Gemini Web Connected Apps URL verification, OAuth 2.1 Dynamic Client Registration, and long-lived connector reliability:

1. **Origin-root MCP mount (`/{$}`)**: Mounts the authenticated stateful MCP handler at `/{$}` alongside `/mcp`, answering `HEAD /` and `POST /` probes with RFC 9728 `401` + `WWW-Authenticate` and allowing either `https://<host>` or `https://<host>/mcp` as the MCP Server URL.
2. **`HEAD` on all discovery endpoints + `/mcp` OIDC path**: Supports `HTTP HEAD` on `/.well-known/oauth-protected-resource*`, `/.well-known/oauth-authorization-server*`, and `/.well-known/openid-configuration*`, plus `/.well-known/openid-configuration/mcp`.
3. **Subdomain-wildcard callback allowlist (`https://*.domain/*`)**: Expands `DefaultOAuthRedirectPatterns()` with `https://*.googleusercontent.com/*`, `https://*.google.com/*`, `https://*.anthropic.com/*`, and `https://*.openai.com/*` alongside `claude.ai`, `chatgpt.com`, and loopback — accepting all 6 Google Connected Apps callback environments out of the box while continuing to block arbitrary unapproved callback hosts by default (with explicit `"https://*"` available as an opt-in).
4. **30-day default OAuth access token TTL**: Raises default `oauth.access_token_ttl_seconds` from `3600` to `2592000` (30 days, configurable up to `31536000`) so hosts that do not proactively refresh short-lived access tokens stay connected seamlessly.
5. **Zero-secret OAuth probe diagnostics**: Emits server-owned constant `amg_oauth` events (`route`, `method`, `status`, `reason`) without logging URLs, query parameters, headers, or tokens.
6. **`os.Root` + `O_NONBLOCK` Skill confinement**: Replaces `EvalSymlinks` -> `os.Open` in `skills_models.go` with `os.OpenRoot(skillBase)` + `O_RDONLY|syscall.O_NONBLOCK` + regular-file verification, closing symlink-swap TOCTOU and FIFO blocking.
7. **`list_directory` symlink tolerance & AMG self-config brief**: Degrades unresolvable/absolute symlinks (such as NixOS `~/.nix-profile`) to `symlink	-	<name>` instead of failing the full directory listing, and directs newly connected agents to `agent-mcp-go-operations` and `docs/configuration.md` for AMG server settings.
