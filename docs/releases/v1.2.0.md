# AMG v1.2.0

Dynamic discovery and resource tuning. The previous fixed Skill preview/description and MCP summary counts are removed. File/Skill pages, directory/search output, Git, task state and review no longer depend on the legacy display counts. Resource budgets remain bounded and adjustable; security, file confinement, transfer/patch integrity and authenticated access are unchanged.

Use `settings_get` to see all defaults, allowed ranges and live values. Send only the fields you want to change via `settings_update`. Existing configurations load with defaults for omitted keys. Existing clients that send the original three values still work; refresh tool metadata to access the new optional arguments. Native content and upstream helper limits still apply. Skill body and exact MCP schema loading remain on demand.

## Installation and verification

Linux amd64; Go 1.25+. Download the archive and checksums from [v1.2.0](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.2.0), follow the [README](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.2.0/README.md), and preserve your configuration and credentials.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

See [configuration](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.2.0/docs/configuration.md) and [changes](https://github.com/bsbofmusic/agent-mcp-go/compare/v1.1.7...v1.2.0).
