# AMG v1.0.2

AMG is a remote agent workspace over MCP. This patch fixes catalog truncation and schema reuse in the optional shared MCP integration.

## Changes

- Catalog scans allow 30 seconds per route and 45 seconds for the scan phase, with up to eight concurrent routes. Slow but healthy initialization is no longer cut off by the previous ten-second route budget. Route discovery and session cleanup remain separate from the scan budget.
- The official Go SDK reads full, paginated tool catalogs from dynamically discovered routes into the existing disposable index. A later exact-schema lookup can reuse those full schemas without a second upstream initialization. No persistent registry, shared owner, or dependency is added.
- Per-source catalog limits are 100 pages, 10,000 tools, and 16 MiB of serialized metadata, with response-body and SSE-event limits and repeated-cursor rejection.
- Search reports safe per-source failure stages, categories and duration, along with `incomplete` and `unavailableSources`. Expired or outage-retained rows are explicitly `stale` and cannot provide exact schemas.
- Abbreviated legacy catalog entries without `inputSchema` fall back to exact lookup. Exact lookup verifies the requested tool identity.

Chinese lexical ranking is unchanged in this patch. Better catalog coverage makes more tools eligible for ranking, but does not establish a new Top3 success rate or a particular real-agent task time.

## Installation and verification

The validated release target remains **Linux amd64**; source builds require **Go 1.25+**.

Release assets:

- `agent-mcp-go-v1.0.2-linux-amd64.tar.gz`
- `checksums.txt`

Download the [v1.0.2 release](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.0.2), verify the checksum, and follow the [README quick start](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.0.2/README.md#quick-start). Preserve an existing configuration and token; the fresh-install setup refuses to overwrite them.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

The exact release commit must pass main-branch CI before tagging. Live tests require an explicit `AGENT_MCP_GO_CONFIG` and documented opt-ins; skipped tests do not establish a live call.

## Client verification and compatibility

Workspace files, transfer, review UI, native attachment contracts, task scopes and stored checkpoints are unchanged. Real attachment authorization/import, saved bytes and SHA-256, review-card rendering, Chinese autonomous tool selection and end-to-end discovery time require client-specific testing. This patch does not claim those manual acceptance results.

Routes must support the same reachable Streamable HTTP transport already used for direct upstream tool calls; AMG adds no custom upstream authentication headers. The shared CLI remains the route-discovery owner and supports legacy exact-schema fallback and compatibility wrappers.
