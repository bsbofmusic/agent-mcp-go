# AMG v1.0.0

The first public version of **AMG / Agent MCP Go** provides a general-purpose remote agent workspace over MCP. A client can inspect and edit a remote project, run commands, review changes, and transfer files through one authenticated workspace server.

## Included capabilities

- File browsing and search, bounded text reads/writes, structured patches, and image inspection.
- Shell execution with incremental output, process-session handles, stdin, cancellation, and timeouts; Git and project-instruction tools. Clean Git status returns an explicit native report.
- Text reads reject non-regular files before scanning, so an open FIFO cannot hold a read request waiting for input.
- Streaming transfer, offset-based chunked upload, no-clobber by default, and file export through MCP resources.
- Review resources, task plans and notes, and scoped task handover across connections.
- Fresh instructions on MCP initialization/discovery, capped at 24 KiB, with an optional Skills preview capped at 13 KiB.
- Optional discovery/read access to an existing Skills directory, and discovery/search/calls through an existing shared MCP installation. Semantic memory can use an operator-provided MemOS route.

The core workspace runs without shared modules. This release does not bundle a gateway, shared MCP CLI, Skill library, memory service, TLS proxy, or tunnel manager.

## Supported release target

**Validated:** Linux amd64. Source builds require **Go 1.25+**. Server-side Shell work requires a POSIX shell; Git tools require Git. Other architectures and operating systems are not claimed as validated by this release.

Release assets:

- `agent-mcp-go-v1.0.0-linux-amd64.tar.gz`
- `checksums.txt`

Download from the [v1.0.0 release](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.0.0). Follow the [README quick start](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.0.0/README.md#quick-start) to verify with `sha256sum`, unpack, generate a configuration and `0600` token for your actual home, and start AMG in the foreground. The example configuration uses `/home/amg` placeholders; AMG does not expand home variables in JSON.

For remote clients, provide your own HTTPS ingress and static Bearer header. Use `/mcp` for stateful clients and `/mcp/stateless` when the client does not preserve MCP session headers. `/healthz` returns `ok\n` without authentication. See [integrations](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.0.0/docs/integrations.md).

## Verification

The following commands are reproducible checks for a source checkout; they are not a claim that every deployment or client UI has passed them.

```sh
CGO_ENABLED=0 go test -count=1 ./...
go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

Live network tests are opt-in. They require an explicit configuration path through `AGENT_MCP_GO_CONFIG` and read only that configuration's token file; they do not automatically discover home-directory credentials. Use a disposable workspace and a configuration pointing to a server you are authorized to test. Integration cases involving shared services require those optional services to be configured.

```sh
AGENT_MCP_GO_CONFIG="$HOME/.config/agent-mcp-go/config.json" \
AGENT_MCP_GO_LIVE=1 \
CGO_ENABLED=0 go test -count=1 -run '^TestLive' .
```

To test an external ingress, additionally set `AGENT_MCP_GO_ENDPOINT` to your HTTPS MCP URL. Dedicated transfer suites have separate opt-ins (`AGENT_MCP_GO_TRANSFER=1` and `AGENT_MCP_GO_LARGE_TRANSFER=1`); the large test requires HTTPS and a file limit of at least 300 MiB. Check the tests' prerequisites and available disk/network capacity before running them.

Validate your actual client separately: initialize, list tools, read an environment and workspace file, run a harmless command, and transfer a temporary file in each required direction. Confirm unauthenticated MCP requests fail. Test review and attachment presentation in the intended host instead of inferring UI support from SDK-level success.

## Known limitations

- The Bearer token grants trusted OS-user code execution. Built-in file operations use a workspace root boundary; Shell is not sandboxed by that boundary.
- Scopes are logical namespaces, not ACLs. The same explicit scope resumes saved plans/notes/project context, not a transcript or active Shell after restart.
- Interactive TTY applications are unsupported.
- Rollback is best effort. In-process locks do not provide cross-process compare-and-swap against external writers.
- Capability transfer URLs are usable without Bearer for 20 minutes and must be kept secret; tickets do not survive restart.
- HTTP proxies, client size/time limits, and host UI features can constrain otherwise supported server operations. ChatGPT native review cards and attachment import/export remain host-dependent.
- No OAuth flow, ingress provisioning, or bundled shared stack is provided.

Read the [security model](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.0.0/docs/security.md) and [configuration reference](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.0.0/docs/configuration.md) before deployment.
