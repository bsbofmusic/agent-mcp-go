# AMG v1.1.1

This maintenance release keeps AMG's module-first architecture and adds bounded diagnostics for intermittent slow requests.

## Changes

- An active recognized RPC exceeding two seconds gets one `slow` event with `level: WARN`, the existing request ID and its current stage. File open/read and command start/output-wait stages distinguish server work without logging paths, commands, arguments or content.
- Completion still records the elapsed time and outcome. HTTP streams and unknown notification methods are excluded from slow warnings. Diagnostics do not cancel, retry or replay operations.
- Local official-SDK regressions cover reconnecting, fresh tool lists, explicit-scope continuity and a write whose response is lost. Client reconnection and cached UI metadata remain controlled by the client.
- Independent read-only inspection may use bounded client-side parallel calls; writes remain ordered. No daemon, heartbeat, cache, index, routing table, dependency or public tool is added.

A historical intermittent 60-second timeout is not claimed to be fixed. Real ChatGPT, DSH and Doubao experience remains a user acceptance step.

## Installation and verification

The release target is **Linux amd64**; source builds require **Go 1.25+**.

Download `agent-mcp-go-v1.1.1-linux-amd64.tar.gz` and `checksums.txt` from [v1.1.1](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.1.1), verify the checksum and follow the [README](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.1/README.md#quick-start). Preserve existing configuration and credentials.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

Independent review precedes promotion. Exact-SHA main CI must pass before tagging, and the downloaded release must pass an isolated install smoke before an atomic, reversible AMG-only upgrade.

See [security](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.1/docs/security.md) and [changes since v1.1.0](https://github.com/bsbofmusic/agent-mcp-go/compare/v1.1.0...v1.1.1).
