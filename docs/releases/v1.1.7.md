# AMG v1.1.7

Patch release for dynamic Skill discovery. `skills_list` now matches a case-insensitive literal substring of either the name or catalog description. For example, a Skill describing `.xlsx` files can be found by searching `xlsx`, even if its name is different. Reads still use the existing bounded canonical-directory path. No new dependencies, indexes, caches, configuration, or tool parameters are required. This is literal filtering, not semantic search or translation.

## Installation and verification

Linux amd64; source builds require Go 1.25+. Download the archive and `checksums.txt` from [v1.1.7](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.1.7), verify the checksum, and follow the [README](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.7/README.md#quick-start). Preserve existing configuration and credentials.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

See [changes since v1.1.6](https://github.com/bsbofmusic/agent-mcp-go/compare/v1.1.6...v1.1.7).
