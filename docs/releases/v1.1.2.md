# AMG v1.1.2

This maintenance release protects existing task data and improves cancellation in file and session requests. It keeps AMG's module-first architecture.

## Changes

- `remember` preserves an existing notes file when reading it fails and rejects JSON `null` instead of panicking. Only a missing file is treated as a new record.
- `read_file` checks request cancellation before opening and between scan operations, including skipped lines before the requested offset. This cooperative check does not interrupt an individual kernel read. Normal page and output limits remain unchanged.
- Session input writes and output waits honor request cancellation. Canceling a request does not stop its process session or automatically replay input. A failed input write reports the written-byte count; inspect session state before deciding what to send next.
- Existing request diagnostics now distinguish route discovery, shared-helper connection/call/close and native upstream connection/call/close. Concurrent fallback work retains one parent scan stage. No dynamic target names, URLs, arguments or results are logged.

These changes add no dependency, daemon, cache, ranking model, route inventory or public tool. They do not prove that a historical intermittent 60-second client timeout has been resolved. Actual client reconnection and native UI behavior remain client acceptance steps.

## Installation and verification

The release target is **Linux amd64**; source builds require **Go 1.25+**.

Download `agent-mcp-go-v1.1.2-linux-amd64.tar.gz` and `checksums.txt` from [v1.1.2](https://github.com/bsbofmusic/agent-mcp-go/releases/tag/v1.1.2), verify the checksum and follow the [README](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.2/README.md#quick-start). Preserve existing configuration and credentials.

```sh
umask 077
CGO_ENABLED=0 go test -count=1 ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -buildvcs=false -trimpath -o agent-mcp-go .
```

Promotion requires independent review and successful exact-SHA main CI before tagging. The downloaded release is checked in an isolated installation before an atomic, reversible AMG-only upgrade. File-transfer and ingress configuration are unchanged.

See [security](https://github.com/bsbofmusic/agent-mcp-go/blob/v1.1.2/docs/security.md) and [changes since v1.1.1](https://github.com/bsbofmusic/agent-mcp-go/compare/v1.1.1...v1.1.2).
